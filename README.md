# Civil Engineering Student Portfolio - Himanshu Kumawat

A modern, responsive, engineering-themed personal portfolio website built specifically for **Himanshu Kumawat**, a first-year undergraduate student in **Civil Engineering**.

---

## 🌟 Pages & Architecture

This portfolio features **7 dedicated pages** with seamless navigation:

| Page | File | Description |
|---|---|---|
| **Home** | `index.html` | Hero banner with truss blueprint diagram, quick stats, bio highlights, and previews of all sections |
| **About Me** | `about.html` | Personal statement, engineering philosophy, 4 key focus areas, and extracurriculars |
| **Education** | `education.html` | First-year B.Tech Civil Engineering syllabus breakdown, practical labs, Class XII & X records, and 4-year roadmap |
| **Skills** | `skills.html` | Categorized technical skills: CAD Drafting (AutoCAD, SketchUp), Structural Mechanics, Field Surveying, Lab Testing, Excel & Python |
| **Projects** | `projects.html` | Interactive category filters & 6 detailed first-year projects with vector graphics and case study popups |
| **Certifications** | `certifications.html` | Autodesk AutoCAD, NPTEL IIT courses, Green Building certifications with verification modals |
| **Contact** | `contact.html` | Interactive contact form with input validation, 1-click email copy, GitHub & LinkedIn links, and FAQ |

---

## 🚀 Key Features

- **Civil Engineering Blueprint Aesthetic:** Technical grid styling, blueprint cyan (`#38bdf8`) & safety amber (`#f59e0b`) accents, glassmorphic cards, and custom vector diagrams.
- **Dark / Light Mode:** Built-in theme switcher with smooth transition and persistent memory via `localStorage`.
- **Zero Dependencies:** Pure vanilla **HTML5**, **CSS3**, and **JavaScript**—no Node.js, npm, or build step required. Works instantly by double-clicking `index.html`.
- **Fully Responsive:** Looks great across mobile smartphones, tablets, laptops, and ultra-wide desktop monitors.
- **Interactive Modals:** Detailed project case study modals and certificate preview dialogs.
- **GitHub & LinkedIn Integration:** Prominently featured in the navbar, hero section, contact cards, and footer.

## 🌐 Free Deployment via GitHub Pages

1. Create a new repository on your GitHub account (e.g., `himanshu-portfolio` or `<your-username>.github.io`).
2. Push all files in this folder to the repository.
3. Go to **Settings** > **Pages** in your GitHub repository.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. Your live portfolio will be published at:
   `https://<your-username>.github.io/`
